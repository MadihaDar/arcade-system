# Arcade System

A console-based Arcade System developed in **C++** as part of an **Object-Oriented Programming (OOP)** course. The project combines multiple interactive games into a single application while applying core OOP principles such as classes, objects, inheritance, encapsulation, abstraction, and modular software design.

The system provides a menu-driven gaming environment where users can select and play different games, including Hopscotch, Typing Game, TriviaTactoe, and an RPG Adventure Game.

---

## Games Included

### 🎮 Hopscotch

A game based on movement and scoring mechanics where players navigate through levels while following game rules and tracking their progress.

---

### ⌨️ Typing Game

A typing speed and accuracy challenge that evaluates the player's performance based on typing speed, correct inputs, and mistakes.

Features:
- Word-based challenges
- Accuracy calculation
- Performance tracking

---

### ❓ TriviaTactoe

A combination of trivia questions and Tic-Tac-Toe mechanics where players answer questions correctly to make moves on the board.

Features:
- Question-based gameplay
- Interactive board system
- Score tracking

---

### ⚔️ RPG Game

A role-playing adventure game where players interact with characters, manage attributes, and progress through different scenarios.

Features:
- Character creation
- Player statistics
- Combat mechanics
- Game progression system
